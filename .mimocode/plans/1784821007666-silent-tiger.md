# Private Browser v3.3 Upgrade Plan

## Overview
Bản cập nhật v3.3 tập trung vào: ổn định, làm đẹp UI, thêm nhiều tính năng mới, và cải tiến kỹ thuật.

---

## 1. STABILITY IMPROVEMENTS (Ổn định)

### 1.1 Memory & Performance
- **File**: `BrowserView.swift` - Thêm cleanup khi tab bị ẩn quá lâu (memory pressure)
- **File**: `DownloadManager.swift` - Thêm retry logic cho download bị lỗi network
- **File**: `ContentBlocker.swift` - Thêm error logging chi tiết hơn

### 1.2 Error Handling
- **File**: `BrowserController.swift` - Thêm timeout handling cho navigation
- **File**: `UserscriptManager.swift` - Validate script trước khi inject
- **File**: `PrivacyManager.swift` - Thêm completion callback với error info

### 1.3 Concurrency Safety
- **File**: `DownloadManager.swift` - Hoàn thiện thread-safe cho tất cả operations
- **File**: `TabsManager.swift` - Đảm bảo thread-safe cho tab operations

## 3. NEW FEATURES (Tính năng mới)

### 3.1 Bookmark/Favorites System
**Files mới**:
- `Models/FavoriteManager.swift` - Quản lý bookmark
- `Views/FavoritesView.swift` - Hiển thị bookmark
- `Views/AddFavoriteView.swift` - Thêm bookmark

**Tính năng**:
- Lưu URL + title + favicon
- Organize theo folder
- Search trong bookmark
- Export/Import bookmark

### 3.2 Find in Page
**Files mới**:
- `Views/FindInPageView.swift` - UI tìm kiếm
- Extension trong `BrowserController.swift`

**Tính năng**:
- Tìm text trong trang hiện tại
- Đếm số kết quả
- Next/Previous navigation
- Highlight kết quả

### 3.3 QR Code Scanner
**Files mới**:
- `Views/QRCodeScannerView.swift` - Camera scanner
- `Models/QRCodeManager.swift` - Xử lý QR

**Tính năng**:
- Quét QR Code từ camera
- Tự động mở URL từ QR
- Lưu lịch sử quét

### 3.4 Quick Actions (Widget-like)
**Files mới**:
- `Views/QuickActionsView.swift` - Panel nhanh
- `Models/QuickAction.swift` - Data model

**Tính năng**:
- Recent sites
- Frequently visited
- Custom shortcuts
- Search suggestions

### 3.5 Advanced Privacy Features
**Files mới**:
- `Models/PrivacyReport.swift` - Báo cáo privacy
- `Views/PrivacyReportView.swift` - Hiển thị report

**Tính năng**:
- Đếm số tracker bị chặn

- Hiển thị network activity
- Privacy score

### 3.6 Custom Themes
**Files mới**:
- `Models/ThemeManager.swift` - Quản lý theme
- `Views/ThemeEditorView.swift` - Chỉnh sửa theme

**Tính năng**:
- Dark/Light/Auto modes
- Custom accent colors
- Gradient backgrounds
- Save/load themes

## 4. TECHNICAL IMPROVEMENTS (Cải tiến kỹ thuật)

### 4.1 Architecture
- Tách `BrowserController` thành `NavigationController` + `WebContentController`
- Thêm `Coordinator` pattern cho complex views
- Implement `Dependency Injection` cho managers

### 4.2 Code Quality
- Thêm `@MainActor` annotations
- Thêm `Sendable` conformance
- Thêm unit tests cho critical paths
- Thêm documentation comments

### 4.3 Performance
- Lazy loading cho tab previews
- Image caching cho favicons
- Debouncing cho URL input
- Background task scheduling
