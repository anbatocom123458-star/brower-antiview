# v4.1 Bug Fixes & Polish Plan

## Summary
Fix issues found after v4.0 release: missed version config, production print statement, thread safety, deprecated API, and minor polish.

---

## Issue 1 — MARKETING_VERSION mismatch (Critical)

**File:** `project.yml:37`
**Problem:** `MARKETING_VERSION: "3.4"` was not updated to v4.0. XcodeGen uses this to generate the Xcode project, so builds would produce v3.4 despite Info.plist saying v4.0.
**Fix:** Change to `MARKETING_VERSION: "4.0"` and `CURRENT_PROJECT_VERSION: "2"`.

---

## Issue 2 — Production print() statement (Medium)

**File:** `Sources/PrivateBrowser/WebView/ContentBlocker.swift:71`
**Problem:** `print("⚠️ Không thể biên dịch bộ chặn quảng cáo: ...")` runs in production builds.
**Fix:** Wrap in `#if DEBUG` / `#endif`.

---

## Issue 3 — PrivacyReport thread safety (Medium)

**File:** `Sources/PrivateBrowser/Models/PrivacyReport.swift`
**Problem:** `incrementBlockedTracker()`, `incrementBlockedAd()`, `incrementRequest()` modify `@Published` properties. These could be called from WebKit delegate callbacks which run off the main thread, causing runtime warnings or undefined behavior.
**Fix:** Dispatch property mutations to `DispatchQueue.main` inside each increment method.

---

## Issue 4 — Deprecated UIScreen.main.bounds (Medium)

**File:** `Sources/PrivateBrowser/Models/FloatingWindowManager.swift:48`
**Problem:** `UIScreen.main` is deprecated since iOS 16. The app targets iOS 16+.
**Fix:** Use a window-scene-based approach: `UIApplication.shared.connectedScenes.first?.windows.first?.bounds ?? UIScreen.main.bounds` (fallback to UIScreen.main for safety on older devices).

---

## Issue 5 — Toolbar button count (Low)

**File:** `Sources/PrivateBrowser/Views/BottomToolbarView.swift`
**Problem:** BottomToolbar now has 8 buttons (back, forward, reload, tabs, zoom, downloads, devtools, panic, menu). On smaller devices (iPhone SE), buttons may be cramped.
**Fix:** Reduce Panic button icon size from 18 to 16 to match other buttons. No structural change needed — the `maxWidth: .infinity` layout distributes space evenly.
